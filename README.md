**Butterflies and Bees**, or **ButterBee** for short, is an add-on for [**CliffTree**](https://modrinth.com/datapack/clifftree) adding new biome-based variations for several mobs. With new variations for cows, pigs, chickens, wolves, and more, the world is sure to feel much more diverse!

<div align="center">
<h4>
⚠️ Usage Notice ⚠️
</h4>
</div>

When using the datapack version, you need to download and enable the ButterBee [resource pack](https://modrinth.com/resourcepack/butterbee-rp). Since version 1.0.4, certain variants may not spawn without CliffTree installed.
